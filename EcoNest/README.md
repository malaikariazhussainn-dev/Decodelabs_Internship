# 🌱 EcoNest — Sustainable Living Website

> **Make Your Home a Better Place for the Planet.**

EcoNest is a clean, modern, and responsive static website focused on promoting sustainable living and environmentally conscious choices at home.

The project presents practical ideas and simple habits that can help people reduce energy consumption, minimize waste, use water responsibly, and create a more eco-friendly home environment.

## 📌 Project Overview

EcoNest was developed as a **Frontend Development Internship Project** at **Decode Labs**.

The primary goal of this project is to demonstrate fundamental frontend development skills by creating a well-structured static webpage using **HTML5 and CSS3**.

The website focuses on:

- Sustainable living
- Energy conservation
- Waste reduction
- Responsible water usage
- Eco-friendly homes
- Mindful everyday choices

---

## ✨ Features

### 🏠 Hero Section
An attractive introductory section that presents the purpose of EcoNest and encourages visitors to make sustainable choices.

### ℹ️ About EcoNest
Introduces the concept of sustainable living and explains how small choices at home can contribute to a healthier environment.

### 🌿 Sustainable Ideas
A dedicated section presenting practical sustainability ideas:

- Save Energy
- Reduce Waste
- Use Water Wisely
- Choose Better

### 💡 Practical Tips
Provides simple and actionable tips for adopting environmentally friendly habits.

### 🏡 Eco-Friendly Home
Highlights principles that can help create a more sustainable and comfortable home.

### 🖼️ Inspiration Gallery
A visual section showcasing natural spaces, mindful choices, and green living concepts.

### 📣 Call-to-Action
Encourages visitors to start with small sustainable choices and gradually turn them into everyday habits.

### 🔗 Navigation
Simple and organized navigation allows visitors to move between the major sections of the website.

### 📱 Responsive Layout
The website is designed to adapt to different screen sizes, including:

- Desktop
- Tablet
- Mobile
